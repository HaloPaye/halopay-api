# Contributing to HaloPay API

We welcome contributions from the developer community! HaloPay is built to provide reliable financial rails in crisis zones.

## Development Workflow

1. Fork & clone the repository.
2. Create a feature branch (`git checkout -b feat/your-feature-name`).
3. Follow the **Conventional Commits** standard (`feat(api): ...`, `fix(api): ...`, `test(api): ...`).
4. Ensure all unit tests pass (`npm test`).
5. Open a Pull Request for code review.

## Pull Request Rules
- Code must be formatted using ESLint.
- All new features must include unit tests.
- Title must follow the Conventional Commits specification.
