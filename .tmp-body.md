### Summary
The `SEP10Service` currently allows unbounded auth requests. We need to implement a Redis-backed rate limiter to prevent brute-force attacks on the challenge endpoint.

### Acceptance Criteria
- [ ] Integrate `ioredis` client.
- [ ] Add sliding window rate limit middleware (100 req/min).
- [ ] Return 429 status code on exhaustion.

### Tech Stack
