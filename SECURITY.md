# Security Policy

## Responsible Disclosure

If you discover a security vulnerability within HaloPay API, please report it responsibly to `security@halopay.io` or reach out directly to maintainers via Telegram ([@HaloPayDev](https://t.me/HaloPayDev)).

Please do not disclose security issues publicly until we have addressed them.

## Audit Disclaimer

This repository is currently in active development for the Drips Wave program and has not yet undergone a formal third-party smart contract and API security audit.
